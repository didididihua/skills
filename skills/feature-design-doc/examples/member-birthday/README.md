# 示例：会员生日礼

一个虚构的功能，四个部分都写了，用来演示每种组件和图：

| 文件 | 部分 |
|---|---|
| `【需求设计】会员生日礼.md` | 需求设计：场景、需求拆解（`::: board`）、业务规则、验收标准、待确认 |
| `【功能原型】会员生日礼.md`、`.proto.js` | 原型交互：一个新增页面、一个改动页面，用通用的 `admin` 皮肤 |
| `【技术文档】会员生日礼.md` | 技术方案：分层架构（`::: arch`）、时序图、流程图、ER 图、状态图、上线步骤（`::: steps`），每张图都有图解 |
| `【决策记录】会员生日礼.md` | 决策记录：四条决策，其中一条待确认 |
| `【设计文档】会员生日礼.html` | 构建结果，直接用浏览器打开 |

重新构建：

```bash
cd ../../scripts && PUPPETEER_SKIP_DOWNLOAD=1 npm install
node build.mjs "../examples/member-birthday/【技术文档】会员生日礼.md"
```
