## 0 概览

本期一个新页面、一个改动页面：营销菜单下新增「生日礼」设置页，会员详情增加生日礼记录。

::: kpi
- **2** 个页面 | 1 个新增，1 个改动
- **1** 处与 PRD 不同 | 发送时间由运营配置（G1） {warn}
- **1** 项待确认 | 会改变设置页的样子（B2） {warn}
:::

::: journey
- **配置生日礼** 运营第一次开通，或调整券和发送时间。
  - P1 生日礼设置 【新增】
- **查看效果** 运营或客服查某个会员有没有收到。
  - P2 会员详情 【改动】
:::

> [!NOTE] 怎么看原型
> 页面上方的「状态」切换同一页面的不同情况；改动页面还能切「现状」「方案」，或用「对比」拖动分界线看改了哪里。紫色编号是新增，琥珀色编号是改动，点编号可以看右侧说明；「改动说明」页签写了前端、接口怎么改。接口、数据和执行流程在右上角的「技术方案」里。

## 1 原型与功能说明

::: proto P1 | 生日礼设置 | 新增页面
运营在这里配置一次：送哪张券、提前几天、几点发、用什么渠道提醒。保存后次日起生效。

1. 【新增】**菜单入口**。营销 › 生日礼，和营销活动并列；有营销权限的账号可见。
2. 【新增】**启用开关**。关闭后从次日起停止发放，已发的券不受影响（BR-1）。
3. 【新增】**生日券**。从券模板里选一张；只能选「可用」状态的模板，未选时不能保存。
4. 【新增】**提前天数**。0 到 7 天，默认 3 天（BR-3）。
5. 【新增】**发送时间**。9:00 到 20:00，整点，默认 10:00（BR-4）；PRD 要求 0 点，待 B2 确认。
6. 【新增】**提醒渠道**。订阅消息默认勾选；短信可选，会员没有订阅时才发短信，消耗短信余额。

- 前端：新增路由 `/marketing/birthday-gift`，表单组件沿用营销活动的 `FormItem`。
- 接口：查询规则、保存规则，见技术方案 §2.1。
:::

::: proto P2 | 会员详情 | 改动页面
在会员详情的权益区域增加「生日礼记录」，客服能直接回答「我的生日券呢」。

> 现状：会员详情有基本信息、积分和券包，没有生日礼相关信息。

1. 【新增】**生日礼记录**。按年份倒序：发放时间、券名称、券状态、提醒结果；没有记录时显示「暂无生日礼记录」。
2. 【改动】**生日**。原来只显示日期，现在旁边标出今年是否已发生日礼。

- 前端 `pages/member/detail/Benefits.tsx`：新增记录卡片。
- 接口：会员详情接口增加 `birthdayGifts` 字段，见技术方案 §2.2。
:::
