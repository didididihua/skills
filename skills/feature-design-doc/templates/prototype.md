## 0 概览

一段话：本期改哪些页面，各改什么。

::: kpi
- **N** 个页面 | X 个新增，Y 个改动
- **N** 处与 PRD 不同 | 列出要点 {warn}
- **N** 项待确认 | 会改变页面的样子，见 §2 {warn}
:::

::: journey
- **任务一** 用户为了什么来到这些页面。
  - P1 页面名 【改动】
- **任务二** ……
  - P2 页面名 【新增】
:::

> [!NOTE] 怎么看原型
> 页面上方的「状态」切换同一页面的不同情况；改动页面还能切「现状」「方案」，或用「对比」拖动分界线看改了哪里。紫色编号是新增，琥珀色编号是改动，点编号可以看右侧说明；「改动说明」页签写了前端、接口怎么改。接口、数据和执行流程在右上角的「技术方案」里。

## 1 原型与功能说明

::: proto P1 | 页面名 | 改动页面
一句话：这页改了什么。

> 现状：这页现在是什么样。

1. 【新增】**名称**。行为、限制、默认值。
2. 【改动】**名称**。原来怎样，现在怎样。

- 前端 `pages/…/xxx.tsx`：改什么。
- 接口：新增或修改哪些字段。
:::

::: proto P2 | 页面名 | 新增页面
一句话：这页做什么。

1. 【新增】**菜单入口**。位置、权限。
2. 【新增】**名称**。……

- 前端：新增路由 `/…`。
- 接口：列表、详情、保存。
:::
