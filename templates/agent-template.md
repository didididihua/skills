# Agent 前馈模板

复制到目标仓库后改名使用（推荐入口：`AGENTS.md`，可同时保留 `CLAUDE.md` 指向本文件）。  
启动任务前让 AI **先读入口，再按需打开子文档**。空着的章节写 `无` 或删掉，不要留假内容。

本文件回答两件事：

- **什么文档放进去**：宪法、规格、方案、术语、howto、规范、ADR、错题本
- **前馈**：动手前必须知道的约束，而不是做完再补

---

## 文档地图

| 类型 | 放哪 | 干什么 |
| --- | --- | --- |
| 宪法 | `AGENTS.md` / `CLAUDE.md` | 项目是什么、AI 能做什么、不能做什么 |
| 需求规格 | `docs/sdd/requirements.md` | SDD：要做成什么样 |
| 技术规格 / Plan | `docs/sdd/tech-spec.md` 或已有 plan 路径 | SDD：怎么做、按什么顺序做 |
| 高阶方案 | `docs/architecture/` | C4、非功能、领域模型、专题方案 |
| 术语表 | `docs/glossary.md` | 中英文对齐，避免同词异义 |
| howtos | `docs/howtos/` | 启动、连库、调试、杀端口 |
| 代码规范 | `docs/standards/` 或 `.cursor/rules/` | 命名、分层、语言、API、安全、打样代码 |
| ADR | `docs/adr/` | 已做的架构决策 |
| Bug 错题本 | `docs/bugs/` | 踩过的坑，禁止再犯 |
